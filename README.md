# pixel-dodge

極限シンプルな避けゲー - レトロアーケード風ピクセルゲーム

## 概要

**pixel-dodge** は、キー1つで操作するピクセルキャラクターが迫りくるドット弾幕を回避するアーケード風アクションゲームです。

ファミコン調の8bitサウンドとレトロビジュアルで、懐かしさと緊張感を両立した「シンプルだけどやめられない」中毒性を提供します。

## 機能

### MVP機能
- **ワンキー操作**: 
  - PC: スペースキー or ←→キー
  - スマホ: タップで左右移動

- **弾幕パターン**（3種類ランダム）:
  - ストレート: 中央から3発直線
  - アーク: 5発の扇形
  - ウォール: 6発の壁状

- **スコアシステム**:
  - 生存秒数でスコア加算
  - ハイスコア記録（LocalStorage）
  - 徐々に難易度上昇

- **ゲームオーバー＆即リスタート**: 0.1秒で再開可能

- **レトロCRTモニターエフェクト**: スキャンライン演出

## 操作方法

| デバイス | 操作 |
|---------|------|
| PC（キーボード）| スペースキー: 左右移動 |
| PC（キーボード）| ←→キー: 直接移動 |
| スマホ | タップ: タップした側へ移動 |

## 技術スタック

- **Canvas API**: ゲーム描画
- **Vanilla JS**: ゲームロジック
- **LocalStorage**: ハイスコア保存
- **PWA**: Service Worker, Manifest

## インストール

### ローカル実行
```bash
python -m http.server 8000
# または
npx serve .
```

ブラウザで `http://localhost:8000` を開く

### PWAインストール
1. Chrome/Safariでアプリを開く
2. 「ホーム画面に追加」を選択
3. オフラインでプレイ可能

## デプロイ

### GitHub Pages
1. リポジトリを作成
2. このフォルダの内容をプッシュ
3. Settings > Pages で有効化

### Vercel
```bash
npm i -g vercel
vercel
```
